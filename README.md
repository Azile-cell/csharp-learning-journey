# C# Learning Journey

This repository contains selected C# exercises and applications completed during my first year of programming.

The purpose of this repository is to document my progression from fundamental programming concepts to object-oriented programming, exception handling, file handling, data processing, and Windows Forms development.

## Topics Covered

### 01 - Inheritance
Exercises demonstrating:
- Base and derived classes
- Inheritance
- Constructors
- Method overriding

### 02 - Exception Handling
Exercises involving:
- `try` and `catch`
- Custom exceptions
- Input validation
- Handling program errors safely

### 03 - Object-Oriented Applications
Applications demonstrating:
- Classes and objects
- Methods
- Encapsulation
- Object-oriented program structure

### 04 - Arrays and Data Processing
Exercises involving:
- One-dimensional and two-dimensional arrays
- Loops
- Calculations
- Data processing
- Finding totals, averages, and maximum values

### 05 - Windows Forms
Graphical C# applications created using Windows Forms, including:
- Event-driven programming
- Buttons and controls
- User input
- Calculations
- Basic GUI development

### 06 - Polymorphism
Exercises demonstrating:
- Abstract classes
- Inheritance
- Method overriding
- Polymorphic behaviour
